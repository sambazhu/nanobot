# DashScope（阿里云百炼）原生接入：LLM + 图像生成 + 语音转写

在新分支 `feat/dashscope-native`（基于最新 main）上实现，三个独立子系统接入，共用 `DASHSCOPE_API_KEY`。

## 1. 原生 LLM provider（dashscope_native）

**新文件 `nanobot/providers/dashscope_provider.py`**
- `DashScopeProvider(LLMProvider)`，httpx.AsyncClient（仓库惯例），可注入 `client=` 供测试
- 端点路由：纯文本 → `POST {base}/api/v1/services/aigc/text-generation/generation`；含图片内容 → `.../multimodal-generation/generation`；默认 base `https://dashscope.aliyuncs.com`
- 请求转换：system/tool 角色映射；`image_url` 数组 → `[{"image": url}, {"text": ...}]`；`input.tools` 透传；`parameters` 含 `result_format: "message"`、`max_tokens/temperature/top_p`、`enable_thinking`、`tool_choice`
- 流式 `chat_stream`：`X-DashScope-SSE: enable` + `incremental_output: true`；chunk 解析拆纯函数（bedrock 模式）；content/reasoning/tool_call 三类 delta 回调；空闲超时 `resolve_stream_idle_timeout_s`
- 错误元数据：`{"code","message","request_id"}` → error_status_code/code/type，429/5xx/超时 → should_retry

**接线**：registry.py 新增 ProviderSpec（`name="dashscope_native"`、keywords 不含 qwen 避免抢匹配、`backend="dashscope_native"`、`env_key="DASHSCOPE_API_KEY"`、`model_catalog="builtin"` + 2026 目录：qwen3.8-max / qwen3.7-plus / qwen3.7-flash / qwen3.5-omni-plus / deepseek-v4-pro 等，实现时对照官方文档校准）→ factory.py elif 分支 → schema.py ProvidersConfig 字段 → providers/__init__.py 懒加载映射

**WebUI/文档**：provider-brand.ts 品牌条目；docs/providers.md + configuration.md

## 2. DashScope 图像生成客户端

**`nanobot/providers/image_generation.py` 新增 `DashScopeImageGenerationClient`**（模板：ModelScope 客户端，同为 DashScope 系异步任务模式）
- `provider_name="dashscope_native"`（key/base 从新 provider 配置解析，避免误用 compatible-mode base）
- 原生异步流程：`POST /api/v1/services/aigc/text2image/image-synthesis` + `X-DashScope-Async: enable` → task_id → 轮询 `GET .../tasks/{id}` → results URL
- model_options：qwen-image-3.0-pro、wan2.7-image-pro
- 底部注册块登记

## 3. DashScope 语音转写（ASR）适配器

**`nanobot/providers/transcription.py` 新增适配器类 + `nanobot/audio/transcription_registry.py` 注册**
- 目标模型：qwen-audio-3.0-asr-flash-filetrans（语音消息场景）；实现时先对照官方文档确定调用形态（异步提交/轮询或同步），套用现有 adapter 模式（XiaomiMiMo/StepFun 为参考）
- key/base 解析复用 providers.dashscope_native 配置或 DASHSCOPE_API_KEY
- config：`transcription.provider: "dashscope"`
